# Sreekaram - శ్రీకారం కొత్త సంకల్పానికి

Open `index.html` in a browser. No build step needed.

- `index.html` landing + pricing, `login.html` login/signup, `app.html` customer app, `owner.html` owner console
- Credentials: `USERS.md` / `USERS.csv` (50 users, owner included)
- Plans control features: Starter 6 modules, Pro 11, Business 12
- Demo note: credentials live in client-side `assets/data.js`; use a real backend before production.

## Design
Agriculture theme with a three.js 3D farm island (loaded from cdnjs, needs internet), 3D extruded company name, textured cards and scroll animations.
