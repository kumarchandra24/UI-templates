How a link gets scored

Every link goes through the same four steps, entirely in your browser. Nothing you paste is uploaded.

1. Break the address apart

Protocol, domain, subdomains, top-level domain, path and query are separated so each part can be checked on its own.

2. Extract features

Length, hyphens, digits, IP addresses, “@” tricks, encoded characters, sensitive keywords and redirect hints.

3. Compare with real brands

A link that says “paypal” but lives on another domain, or spells it “paypa1”, is flagged as impersonation.

4. Score and explain

Weights add up to a 0–100 risk score. Under 20 is legitimate, 20–59 suspicious, 60 and above potential phishing.
