Help & FAQ

How to use AlgoLab and the ideas behind it.

How do I run a visualization?

Open a topic, pick an algorithm tab, press Play (or Step to move one frame at a time). Change the input box and press Run to use your own data, or press Random where it appears.

What do the colours mean?

Yellow: items being compared or visited. Coral: items that were swapped or changed. Violet: a selected item, pivot or an item waiting in a queue. Mint: finished or found. Faded: ruled out.

How do I rotate the 3D view?

Drag with the mouse or a finger across the dark stage. The board tilts so you can see depth; it does not change the algorithm.

What input formats are accepted?

Arrays: 1–14 whole numbers separated by commas (0–999). Stack/queue and linked list: commands separated by commas, such as push 5, pop. Trees: level-order values with - for an empty child. Graphs: edges like 0-1, 0-2. Error messages tell you what to fix.

Why is the code shown in Python style?

Python reads almost like pseudocode, so the highlighted line is easy to follow. The same logic applies in Java, C++ or JavaScript.

What do O(n) and O(log n) mean?

They describe how the work grows with input size n. O(1) is constant, O(log n) grows very slowly (halving), O(n) grows in step with the input, O(n log n) is typical for good sorting, O(n²) grows quickly, and O(2ⁿ) explodes.

Which order should I learn in?

Follow the navigation order: Sorting, Searching, Stack & Queue, Linked List, Binary Tree, Graph, Recursion & DP, Problem Solver, then the Quiz.

Does it need internet?

No. Open index.html in any modern browser. There are no libraries or external requests.

Glossary

Pivot: the value quick sort partitions around. Stable sort: equal values keep their original order. Memoization: saving results of function calls. Traversal: visiting every node in a defined order. BFS / DFS: breadth-first / depth-first search.
