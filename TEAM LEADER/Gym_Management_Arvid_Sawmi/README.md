# IronVault — Gym Management

**Owner:** Arvid Sawmi  
**Theme:** Black & White  
**Type:** Responsive front-end gym management application

## Run
Open `index.html` in Chrome/Edge/Firefox. No server or installation is required.

## Working features
- Dashboard with live-looking KPI cards and revenue chart
- Member directory with search and status filters
- Add/edit member modal
- CSV member export
- Attendance check-in and live list
- Weekly attendance visualization
- Workout program creation and assignment flow
- Payment recording and searchable transaction ledger
- Trainer management
- Reports and progress targets
- Settings with editable gym profile and toggles
- Dark/light theme toggle
- Notifications
- Responsive mobile sidebar
- Toast notifications
- Print reports
- Local browser state for theme preference

This is a self-contained demo application. Data is stored in JavaScript memory during the browser session; connect a backend/database if persistent multi-user storage is required.
