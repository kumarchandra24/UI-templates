# PolicyFlow — Policy Management
### Arvid — Self-contained frontend application

A polished policy governance and management dashboard built with **HTML, CSS and vanilla JavaScript**.

## Features
- Animated governance-themed UI with dark/light mode
- Overview dashboard with KPI cards, live-style chart, lifecycle, activity feed and attention center
- Full Policy Library with search, category/status filters and policy creation
- Approval Center with working review/approve actions
- Compliance Center with control-domain health and exceptions
- Audit Trail with search and CSV export
- Departments management with add-department modal
- People & Roles with invite workflow
- Documents / evidence vault with file upload and drag-and-drop
- Reports & Analytics with printable report and CSV export
- Notification center with mark-all-read
- Settings with working automation toggles and saved preferences
- Responsive mobile sidebar
- Toast notifications
- Local browser theme persistence
- No backend or external database required

## Run
1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge/Firefox.
3. Everything is client-side and works without a server.

## Notes
Data is demo data stored in JavaScript arrays. Newly created items exist during the current browser session.
