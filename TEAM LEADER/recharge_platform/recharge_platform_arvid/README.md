# Arvid Recharge Hub

A polished, responsive recharge and bill-payment dashboard built with plain HTML, CSS and JavaScript.

## Included
- Dashboard with live-looking stats and recent activity
- Mobile, DTH and broadband recharge flow
- Payment confirmation modal
- Popular plan catalog with filters
- Transaction search/filter and CSV export
- Wallet and add-money interaction
- Electricity, water, gas, card, insurance and subscription bill center
- Saved billers
- Favorite recharge contacts
- Add/remove contacts
- Support center with FAQ interactions
- Notifications and profile modal
- Dark/light theme persisted in localStorage
- Responsive mobile sidebar
- Animated gradients, ambient blobs, cards and wallet visuals
- No external libraries or backend required

## Run
Open `index.html` in a modern browser.

For a local server:
- VS Code: use Live Server
- Or Python: `python -m http.server`

## Note
This is a fully interactive front-end demo. Payment and recharge actions simulate successful processing locally; no real money or telecom API is connected.
