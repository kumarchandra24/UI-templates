# BMW Drive — Premium Car Booking
User: Tyler Durden
Sector: Automotive / Mobility

## Features
- BMW model dashboard and featured cars
- Search, body-style filtering and price sorting
- Save/favourite cars with localStorage
- Vehicle details
- Compare up to 3 BMWs
- Booking flow with city, date and payment preference
- My Bookings history
- Test-drive booking
- Finance/EMI estimator
- Responsive premium automotive UI
- Toast notifications
- Reset demo data

## Structure
bmw-car-booking/
- index.html
- style.css
- script.js
- README.md

## Run
Extract the ZIP and open `index.html` in Chrome, or use VS Code Live Server.

This is an original front-end demo. It does not process real vehicle orders or payments and does not connect to BMW systems.
