# TaxFlow — Smart Tax Payment UI

## Team
- LalTanveer
- Mamitha Baiju

## Sector
FinTech / Government Digital Services — Tax Payment

## Features
- Responsive modern tax dashboard
- Tax payment workflow with multiple tax types and payment methods
- Local browser storage for demo payment history
- Automatic digital receipt generation
- Tax calculator with old/new regime estimates
- Upcoming deadline cards
- Payment history and tax filters
- Global payment/reference search
- TaxBot with working chat responses
- Tax insights and recommendations
- Dark mode
- Settings and reset demo data
- Mobile responsive sidebar
- Print/save receipt using browser print
- Toast notifications

## Run
1. Extract the folder.
2. Open `index.html` in Chrome/Edge.
3. No installation or server is required.

## Note
This is a front-end hackathon/demo application. It does not connect to government tax portals, banks, UPI networks, or real payment gateways. Transactions are simulated and stored only in the browser's localStorage.
