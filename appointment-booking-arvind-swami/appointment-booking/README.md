## Research

### What is appointment booking UI?
A healthcare appointment booking interface helps patients discover providers, compare options, choose a visit type and reserve a time slot.

### Common usage
It is used by hospitals, clinics, telemedicine services, diagnostic centers, insurance networks and wellness platforms.

### Why it matters
Healthcare scheduling should reduce friction. Modern products combine provider discovery, availability, appointment management, reminders and patient health information in a single experience.

### Observed design patterns
- Strong primary booking CTA
- Search + category filtering
- Doctor cards with social proof
- Clear status labels
- Calendar-based scheduling
- Time-slot selection
- Patient dashboard metrics
- Progressive disclosure through a booking modal
- Responsive navigation
- Feedback through notifications/toasts

### What this implementation adds
MediNova combines appointment booking with a complete patient dashboard. It adds health insights, medications, records, nearby clinics, appointment calendar, premium care promotion and interactive micro-interactions rather than presenting only a basic booking form.
